# Révisions HEP

QCM guidés puis réponse rédigée, avec aides et retours personnels pour les révisions HEP.

Application statique sans compilation. Progression et brouillons conservés sur l’appareil ; envoi volontaire des retours à Maxim dans une boîte privée ; sauvegarde Google Drive facultative.

Identité visuelle adaptée de [qcm-francais](https://github.com/ultramax333/qcm-francais). Les données et l’application sont indépendantes.
